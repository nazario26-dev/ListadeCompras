# Lista de Compras

Site simples para gerenciar itens de compra.

## Uso

1. Abra `index.html` no navegador.
2. Digite o nome do item no campo.
3. Clique em "Adicionar".
4. Marque itens como comprados ou remova itens.

O site salva a lista no `localStorage` do navegador e também usa cache offline, então os itens permanecem disponíveis ao atualizar a página e mesmo sem conexão.
